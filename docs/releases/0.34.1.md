# 0.34.1

0.34.0 was tagged but its release workflow failed before publication to PyPI.
0.34.1 includes all changes described in the [0.34.0 release notes](0.34.0.md).

This release fixes two test issues. The retention test waits for the real command
to finish before checking its exit code. The pathological glob tests use inputs
that exceed the 250 ms CPU budget within a single regex call.

Product behavior, dependencies and stored data formats are unchanged from
0.34.0. The package still selects contract 37.0.0. Follow the
[0.34.0 upgrade notes](../upgrading.md#0340--2026-11-07) when upgrading from an
earlier release.
