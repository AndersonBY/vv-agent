# 0.28.0

Hosts can read a session's durable context budget and request compaction with a
stable actionId. Reads need no execution lease. They distinguish raw history,
visible history, summary and pending input, and expose unknown model limits.
Manual compaction uses the existing inbox and summary ledger. A running turn
reaches a safe boundary first; cancellation and concurrent input stay intact.
Lifecycle notifications can be reconstructed from thread/events/list.

model/list returns nullable capability and limit fields from the configured
catalog and resolver. Unknown support is not reported as false. Model selection
continues through thread/model/select.

This release adopts contract 30.0.0, App Server v4 and public API inventory v14.
The model/list shape replacement requires a major contract release. There is no
record, inbox or SQL store boundary. Regenerate protocol clients and keep pending
compaction requests on this runtime. Local adoption gates and central release
verification are separate; the contract support matrix records the latter.
