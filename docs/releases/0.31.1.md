# 0.31.1

`import vv_agent` no longer loads the model SDKs. Before this release every new
process paid for importing the Anthropic, OpenAI and vv-llm client packages, even
when it only opened a session store or wrote an inbox item. A fresh process now
imports vv-agent in about 0.46 s instead of 2.4 s on a warm page cache (0.64 s
instead of 4.0 s cold), measured on the release gate host.

The SDKs load the first time you use `VvLlmClient`, `EndpointTarget`, or a
model endpoint binding, so the cost moves to the first model call in a process
instead of disappearing. Public names, `__all__` and the objects you get back are
unchanged, and so is the public API inventory.

No contract, wire, store or dependency change. Contract 32.0.0 is unchanged.
