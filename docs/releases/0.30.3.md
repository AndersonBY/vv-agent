# 0.30.3

Compaction counts DeepSeek, local tiktoken models and Qwen on the worker even
when vv-llm's global token server is configured. A host loading shared settings
no longer makes these checks send the conversation over HTTP.

Counts match vv-llm's whole-conversation count with no token server configured.
Tools, images and message formatting stay the same. DeepSeek and tiktoken keep
their exact version gates and safe text boundaries for incremental caching.
Qwen, unsafe boundaries and unverified versions use a whole local count.
Replaced counting functions still disable incremental caching; an explicitly
replaced message counter remains in control.
Families that use provider counters keep their existing behavior.

Tests compare both global-server configurations with the original local count,
fail if local counting attempts HTTP, and compare compaction decisions and
record bytes through real stores. Remote-counter tests retain their original
request bodies and request counts with and without a global server.

Contract 31.0.0, record schema 1, inbox schema 3 and SQL layouts are unchanged.
No migration or host configuration change is needed.
