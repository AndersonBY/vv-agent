# 0.33.0 — 2026-11-04

Requires contract 33.0.0. This is a major contract release: artifact authorization,
read_file, search and terminal retention behavior change. Record schema 1, inbox
schema 3, SQL schema 3, RunEvent v6 and App Server v5 are unchanged.

Compaction evidence can be read and searched in its current session/task. The
public is_task_artifact_path predicate protects file reads and file metadata.
Scope encoding preserves the full identity with separate task and session type
tags. Other tasks and sessions remain denied, and host ACLs still apply.

Search scans long lines in bounded windows and returns line numbers, character
columns and short match excerpts. It reports the overlap limit instead of
silently skipping a line. read_file accepts start_char with fixed 12,000-character
pages and reports the next position on every truncated page. The max_chars
argument is removed. Page notices count toward body bytes; the digest-bound
cursor remains available. All model-controlled content, glob and child exclusion
matching shares an interruptible request budget. Content timeouts preserve earlier
hits and report incomplete results; discovery timeouts are explicit errors.
Reverse mode is rejected. Unicode word and dotless-i changes are listed in
[upgrading](../upgrading.md).

If command output cannot be saved or first read, the result keeps the confirmed
command status, exit code and directive, plus
`metadata.retention={"status":"unavailable","reason":"artifact_persist_failed"}`.
It has a bounded preview and no artifact/cursor recovery pointer. Hosts must not
retry the command just because output retention failed.

The read_file schema is part of a turn's frozen definition. Old executable turns
close with `handler_schema_or_capability_mismatch` at their next dispatch, even
when the next call uses another tool. Paused turns and turn-level waits reach
the guard after resumption. Drain them on the old runtime before upgrading, or
start new sessions from product history; do not rewrite frozen records.

Only task IDs matching `[A-Za-z0-9][A-Za-z0-9._-]{0,63}` without a lowercase
`s-` prefix keep their old literal directory. Other task IDs and old lossy
compaction scopes lose model read access to their old paths. Stored objects are
not deleted. New sessions do not inherit the old session's artifact grants.

When a guard closes a turn that is not marked cancelled, an already parked,
started provider operation keeps its original unconfirmed wait if cancellation
does not prove a definitive outcome. The terminal record lists it in
`unconfirmed_operations`; no `op_unknown` is written for this case. Later trusted
results are audit-only and do not resubmit work. User cancel/abort keeps its
existing `op_unknown` behavior, including `provider_result_invalid` for invalid
Definitive replies.

See [upgrading](../upgrading.md#0330--2026-11-04) for the transition. Frozen Rust
remains at contract 23.0.0 / package series 0.21.x.
