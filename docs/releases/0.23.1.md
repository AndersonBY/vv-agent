# 0.23.1

Patch release on contract **26.0.0** / public API **v10**; no wire or API change.

- Token usage normalization reads cache writes reported as top-level
  `cache_creation_tokens` (the vv-llm `Usage` shape) and as
  `prompt_tokens_details.cache_write_tokens` (Moonshot kimi-k3, OpenRouter).
  Previously these calls were recorded with `accounting_missing` cache usage, so
  hosts that require provider-reported cache accounting could not bill them.
  Use with vv-llm 0.8.2 or later, which reports Moonshot cache reads as zero when
  the provider omits them.
