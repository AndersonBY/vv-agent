# 0.35.0

A host can let a wait yield to new input without stopping the observed work.
Set `ChildSession(yield_on_steer=True)` or return
`Accepted(handle, yield_on_steer=True)`. The kernel completes every eligible
observation and applies the steer in one commit. Its next model request sees
both. Undeclared unfinished work keeps steering queued.

Children continue and later notify by background rules. A yielded provider
handle closes without query or cancel; late authenticated results only audit.
Same-watermark child terminals precede steering. Optional read-only host callbacks
render the model-visible result; exceptions fall back to the SDK default.
App Server shows the yielded tool as completed.

Read [host usage](../session-kernel.md#yielding-a-wait-to-new-input) and
[upgrade instructions](../upgrading.md#0350--2026-11-08). Optional closed record
fields make declared sessions unreadable by 0.34.1; undeclared waits retain their previous scheduling and declaration bytes.
New long-result archive identities include content SHA-256 for every tool;
existing stored bytes and references are untouched. No SQL migration or dependency changes are required.

Duplicate original receipts use the saved archive reference after validating
the body's digest and length; other result fields and usage still must match.
Local child polling honors store deadlines despite unchanged log/inbox positions.
Root exit hands new input to the current driver or a successor, and parent
recovery drains terminal child delivery before considering another child worker.

The target is contract 38.0.0, a major change to closed record shapes and declared
scheduling. Local producer validation uses `VV_AGENT_CONTRACT_SOURCE`; immutable
contract publication, snapshot synchronization and central adoption remain
release prerequisites. The existing release lock and snapshot are unchanged.
Frozen Rust does not support this capability.

Yield callbacks may perform read-only observation; they cannot write, publish,
retain or transfer files or send messages. Different precommit observations are
allowed; the committed result is final and replay reads records only. Verified
child handles include terminal results and exact terminal references. Original
provider acceptance declarations travel in authenticated provider_evidence even
before park commit. Conflicting attachments reject; conflicting queries fail.
Older readers reject declared inbox values as well as declared records. Local
parked drivers return without spinning; long result candidates use content-bound
immutable identities shared with ordinary tools. There is no SQL migration.

Host wake coalesces an active handle or starts ordinary recovery. A driver exits
after a full tree pass makes no progress and receives no wake marker, including
retained children and terminal delivery. Empty recovery may acquire another
lease and publish status notifications. Cancellation intent is bound to the
target turn; wake failures report the session identity through the host error path.
