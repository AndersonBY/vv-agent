# 0.29.0

thread/fork starts an independent session from an ended-turn history boundary.
A stable forkId makes retries return the same thread across API nodes. Forks
retain the visible context, active accepted summary, effective model and lineage.
Pending inputs, controls, attempts and human waits stay on the source.

Hosts prepare business files and pass an opaque workspace binding. Compaction
artifacts reuse the existing immutable storage interface, copying only missing
artifact bytes when bindings differ. Existing corrupt evidence is rejected.

A successful local drive now clears an obsolete lease retry under the turn lock,
so a completed approval recovery leaves no old timer behind.

This release adopts contract 30.1.0 under App Server v4 and public API inventory
v14. There is no record, inbox or SQL store boundary. Regenerate clients and keep
fork sessions on this runtime or newer. Immutable release publication and central
CI remain required before the contract support matrix can become verified.
