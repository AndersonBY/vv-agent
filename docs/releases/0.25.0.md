# 0.25.0

Contract **28.0.0**, App Server protocol **v3**, public API **v12**.

App Server submissions use stable host/client IDs and expected turns. Repeating
an identical submission returns its original receipt; changing it conflicts.
Thread creation uses an atomic identity without scanning sessions. Controls,
resume and approval answers work across connections and API nodes.

thread/events/list reads bounded record pages, including event offsets within a
record. Detailed thread status separates provider and child work, human waits,
retry backoff, suspension and terminal execution.

AppServerHost.resolve_model reaches SessionDriver. Its default resolves exact
provider model IDs; CLI and interactive use the same provider resolver through
SessionDriver. Frozen empty-route requests reuse their original binding.
Distributed hosts must implement AppServerHost.authorize; the local default
allows every connection. Client inputId/actionId values use 1..128 ASCII letters,
digits, dot, underscore, colon or hyphen. Internal slash IDs cannot be submitted.
Usage records keep the actual model and backend of each retained call.

The default resolver filters the configured backend before matching resolved
model_id, including endpoint-level IDs. A duplicate ID within that backend is
rejected. AppServer.wake(thread_id) lets an embedded host wake committed work.
A non-holder gets one automatic expiry retry; live progress stops it. Observer
positions expire on the last local unsubscribe, and each session independently
backs off and recovers from read failures. Projection and notification I/O do
not hold store locks.

Controller inputs now use controller/ plus the digest. **actionIds submitted
before the upgrade are not deduplicated afterwards**: drain them on 0.24.0 or
do not retry them across the upgrade. No legacy lookup is retained.
session.kernel.drive() returns bool for lease acquisition, not turn completion;
false means the lease was unavailable.

This is **not a store boundary**. Record schema 1, inbox schema 3 and SQLite /
PostgreSQL schemas are unchanged. Upgrade App Server clients together with the
exported schemas and TypeScript bindings. Rust remains frozen at contract
23.0.0 / package 0.21.x.
